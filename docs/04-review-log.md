# 04. 오답노트 (직접 채우세요)

> **이 파일이 이 레포에서 가장 중요합니다.**
> 푼 문제를 기록하지 않으면 같은 실수를 시험장에서 또 합니다.

## 쓰는 법

문제를 풀 때마다 아래 형식으로 한 줄씩 추가하세요. 3분이면 됩니다.

```
### [게임 맵 최단거리] (Lv.2)
- 날짜: 2026-10-10 / 유형: BFS 격자 최단거리
- 결과: 30분 만에 스스로 품 / 답 보고 품 / 못 품
- 막힌 지점: 도착 못 하는 경우 -1을 반환해야 하는데 처리를 안 함
- 배운 것: 시작 칸 dist = 1. 큐가 빌 때까지 못 만나면 -1
- 재도전: [ ] 3일 뒤   [ ] 1주 뒤
```

## 복습 규칙 (Spaced Repetition)

- **답을 보고 푼 문제** → 3일 뒤 + 1주 뒤, 총 2번 다시
- **스스로 푼 문제** → 1주 뒤 1번만
- 재도전에서 또 막히면 → 그 유형 문서를 다시 읽고 유사 문제 2개 더

> 새 문제 10개보다 **복습 3개**가 강합니다. 특히 남은 기간이 짧을수록 더 그래요.
