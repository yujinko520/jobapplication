# DP (동적 계획법) — 2차 관문

> **한 줄 요약**: 큰 문제를 작은 문제로 쪼개고, **답을 기록해서 재사용**한다.

노베이스가 가장 어려워하는 부분입니다. 하지만 **코테에 나오는 DP는 유형이 정해져 있어요.**
아래 6가지 유형만 확실히 하면 실버~골드5 DP는 대부분 풀립니다.

## 1. DP인지 알아보는 신호

- "**경우의 수**를 구하시오" (가짓수가 엄청 큼, `% 1,000,000,007` 같은 게 붙음)
- "**최대/최소** 값을 구하시오" 인데 그리디로는 반례가 있음
- "N번째 항을 구하시오"
- 완전탐색을 해보면 **같은 계산이 반복**됨

## 2. DP 푸는 순서 ★ 이 4단계로만 생각하세요

1. **`dp[i]`가 무엇인지 한 문장으로 정의한다** ← 여기가 90%
2. **점화식을 세운다** (`dp[i]`를 `dp[i-1]`, `dp[i-2]`... 로 표현)
3. **초기값을 정한다** (`dp[0]`, `dp[1]`)
4. **순서대로 채운다**

> **1번 정의를 못 하면 절대 못 풉니다.** 코드를 치기 전에
> "dp[i] = i번째까지 봤을 때 ___의 최댓값" 이라고 **말로 먼저** 적으세요.

## 3. 두 가지 구현 방식

### Bottom-up (반복문) — 기본. 이걸 쓰세요
```python
dp = [0] * (n + 1)
dp[1] = 1
for i in range(2, n + 1):
    dp[i] = dp[i-1] + dp[i-2]
```

### Top-down (재귀 + 메모이제이션)
```python
from functools import lru_cache
import sys
sys.setrecursionlimit(10 ** 6)

@lru_cache(maxsize=None)
def f(n):
    if n <= 1:
        return n
    return f(n-1) + f(n-2)
```

`@lru_cache` 한 줄이면 메모이제이션이 끝납니다. 점화식이 복잡할 땐 top-down이 편해요.
단, **인자가 리스트면 안 됩니다**(hashable해야 함) — 튜플로 바꾸세요.

## 4. 대표 유형 6가지 ★

### 유형 1. 피보나치형 (1차원, 직전 몇 개로 결정)
```python
# 계단 오르기: 1칸 또는 2칸씩 → n칸 오르는 경우의 수
dp[i] = dp[i-1] + dp[i-2]
```
**문제**: 2×n 타일링, 1,2,3 더하기, 계단 수

### 유형 2. 최대 부분 합 (연속)
```python
# dp[i] = i번째를 "반드시 포함"하는 연속 부분합의 최댓값
dp[i] = max(arr[i], dp[i-1] + arr[i])
answer = max(dp)
```
`dp[i-1]`이 음수면 버리고 새로 시작하는 게 이득이라는 아이디어.

### 유형 3. LIS (가장 긴 증가 부분 수열)
```python
# dp[i] = i로 끝나는 증가 수열의 최대 길이   O(n²)
dp = [1] * n
for i in range(n):
    for j in range(i):
        if arr[j] < arr[i]:
            dp[i] = max(dp[i], dp[j] + 1)
answer = max(dp)
```
n이 10만이면 O(n log n) 버전(`bisect` 사용)이 필요합니다 → [`algo/dp.py`](../../algo/dp.py)

### 유형 4. 배낭 문제 (Knapsack) ★ 최빈출
```python
# dp[w] = 무게 w까지 담을 수 있는 최대 가치
dp = [0] * (limit + 1)
for weight, value in items:
    for w in range(limit, weight - 1, -1):     # ★ 역순! (각 물건 1번만)
        dp[w] = max(dp[w], dp[w - weight] + value)
```
- **0/1 배낭** (각 물건 1개): 무게 루프를 **역순**으로
- **무한 배낭** (물건 무제한): 무게 루프를 **정순**으로

이 역순/정순 차이가 배낭 문제의 핵심입니다.

### 유형 5. 2차원 DP (격자)
```python
# 오른쪽/아래로만 이동해서 (0,0)→(n-1,m-1) 최대 점수
dp = [[0] * m for _ in range(n)]
dp[0][0] = board[0][0]
for i in range(n):
    for j in range(m):
        if i > 0: dp[i][j] = max(dp[i][j], dp[i-1][j] + board[i][j])
        if j > 0: dp[i][j] = max(dp[i][j], dp[i][j-1] + board[i][j])
```

### 유형 6. 문자열 DP (LCS)
```python
# dp[i][j] = a[:i]와 b[:j]의 최장 공통 부분 수열 길이
dp = [[0] * (len(b)+1) for _ in range(len(a)+1)]
for i in range(1, len(a)+1):
    for j in range(1, len(b)+1):
        if a[i-1] == b[j-1]:
            dp[i][j] = dp[i-1][j-1] + 1
        else:
            dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

## 5. 자주 하는 실수

- [ ] `dp` 배열 크기를 `n`이 아니라 **`n+1`** 로 잡았나 (1-indexed로 쓰는 게 편함)
- [ ] 초기값 `dp[0]`, `dp[1]`이 맞나 (엣지 케이스 n=1 직접 확인!)
- [ ] 최솟값 구할 때 초기값을 `0`이 아니라 `float('inf')`로 했나
- [ ] `% 1000000007` 빼먹지 않았나
- [ ] 배낭에서 루프 방향(역순/정순) 맞나

## 6. 공부 방법 — 중요

DP는 **"이해했다"와 "풀 수 있다" 사이의 간격이 제일 큰** 주제입니다.
답을 보고 이해했으면 **반드시 창을 닫고 처음부터 다시 쳐보세요.** 이걸 안 하면 절대 안 늘어요.

시간이 부족하다면: **유형 1, 4, 5만** 하세요. 출제 빈도가 압도적으로 높습니다.
