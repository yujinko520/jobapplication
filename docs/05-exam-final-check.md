## §3. 증상 → 원인 역색인 (막혔을 때 여기부터)

### "정답입니다"가 안 뜨는데 에러도 없다

| 증상 | 1순위 의심 |
|---|---|
| 출력이 통째로 이상하다 | **타입 불일치** — `1 in ('1','4','7')` 은 `False`. 에러 없이 조용히 틀림 |
| 결과가 **1 적다 / 마지막이 빠졌다** | **`range` 끝값 `+1`** |
| 일부 케이스만 틀린다 | **초기 상태 / 첫 원소 / 마지막 원소** (§1의 3·5번) |
| 조건을 처리했는데 반영이 안 된다 | `answer = ...` 가 **아래에서 덮어써졌다** → 그 자리에서 `return` |
| 빈 입력에서만 틀린다 | `arr[0]`을 초기값으로 썼다 → `0`에서 시작하도록 고친다 |
| **정사각 격자는 통과, 직사각만 틀린다** | `nx`/`ny` 를 행 수/열 수와 **반대로** 비교했다 |
| **while 이 한 바퀴도 안 돈다** | 경계 조건이 **빈 범위** (`0 <= nx < 0`) / `dist == 0` 을 `!= 0` 으로 뒤집음 |
| **최단거리가 항상 -1** | `while q:` 뒤에 `len(q) > 0` 을 검사했다 (항상 거짓) |
| 거리가 전부 1 | `dist[nx][ny] = 1` 로 썼다 → `dist[x][y] + 1` |
| **시간 초과인데 로직은 맞다** | ① 재귀에 메모가 없다 (같은 값 재계산) → **DP** ② 나머지를 끝에만 했다 |
| `RecursionError` 가 DP 문제에서 | 재귀로 짰다 → **for문으로 아래에서 위로** 쌓는다 |
| `IndexError: list assignment index out of range` | `dp[1]` 을 건드렸는데 `n=1` 이라 칸이 1개 (§1-6) |
| 격자 밖을 읽는데 에러가 안 난다 | `maps[-1]` 은 **맨 아랫줄**이다. 경계 검사 필수 |

### 에러 메시지

| 메시지 | 뜻 |
|---|---|
| `'int' object is not iterable` / `has no len()` / `is not subscriptable` | **정수를 목록처럼 취급**했다. `for i in h:` → `for i in range(h):` |
| `list indices must be integers, not str` | `for x in 리스트` 는 **원소**를 준다. 인덱스가 필요하면 `enumerate` |
| `unhashable type: 'list'` | 리스트를 dict 키/set 원소로 썼다 → **튜플**로 |
| `cannot unpack non-iterable int` | `deque([0,0])` 로 정수를 넣었다 → `deque([(0,0)])` |
| `not enough values to unpack (expected 2, got 1)` | `q.append([(nx,ny)])` 겉 괄호 과잉 → `q.append((nx,ny))` |
| `list indices must be integers, not tuple` | `dist[0,0]` → `dist[0][0]` |
| `TypeError: 'dict' object is not callable` | `d(x)` → `d[x]` |
| `KeyError: 0` | 집계용 dict를 **원본인 줄 알고 읽었다** (이름을 구분하라) |
| `UnboundLocalError` | 루프 안에서만 만들어지는 변수를 **루프 밖에서** 썼다 → 그 자리에서 `return` |
| **`RecursionError`** | ① `sys.setrecursionlimit(100000)` 을 빼먹었다 (격자 문제) ② **`visited` 를 빼먹었다** |
| `SyntaxError` 가 `for` 를 가리킨다 | 컴프리헨션을 `[ ]` 로 감싸지 않았다 |

### "시간 초과" / 효율성 테스트 실패 — **이 순서로 본다**

1. **무한루프가 아닌가?** ← 10/5 기준 내 1순위 원인
   - **반복 중인 리스트에 `append`/`remove`** 했다 (에러 없이 멈춘 것처럼 보인다)
   - `while` 조건이 변하지 않는다
2. 바깥 루프는 보통 필수다. **안쪽을 줄여야 한다** → `√n` / dict / 정렬
3. 같은 계산을 반복하나 → 미리 계산해두기
4. **완전탐색 전에 "변수를 줄일 수 있나?"를 묻는다** (카펫: O(N²) → O(N))

## §4. 외워서 치는 코드

> 각 블록 제목 옆 `[0/2]` = **빈 화면 재현 성공 횟수**. `[2/2]`가 되면 그날 **블록을 지우고 §8로** 옮긴다.
> (BFS 템플릿은 예외 — 외워도 10/24까지 남긴다)

### ★★ `is_prime` — `return True`의 위치가 전부다  `[0/2]`

```python
def is_prime(n):
    if n < 2:                # 0, 1은 소수가 아니다
        return False
    j = 2
    while j * j <= n:        # √n 까지만
        if n % j == 0:
            return False     # 하나라도 나눠지면 즉시
        j += 1
    return True              # ★★ 루프 '밖'
```

`return True`를 `while` 안에 넣으면 1~200 중 **54개 오판** (9, 15, 25를 소수라고 함).

### ★★ 약수 개수 — 같은 √n, 다른 목적  `[0/2]`

```python
cnt, j = 0, 1
while j * j <= i:
    if i % j == 0:
        cnt += 1 if j * j == i else 2    # 제곱수면 1개, 아니면 j와 i//j
    j += 1
```

> **"하나라도 있나" = 즉시 `return` / "몇 개인가" = 끝까지 센다.**

### ★★★ 격자 DFS — 가장 많이 쓰임  `[0/2]`  (10/19 작성)

```python
import sys
sys.setrecursionlimit(100000)       # ★ 격자는 거의 항상 필요 (안 쓰면 RecursionError)

n, m = len(maps), len(maps[0])              # n=행 수, m=열 수
visited = [[False] * m for _ in range(n)]   # ★ [[F]*m]*n 은 금지

def dfs(x, y):
    visited[x][y] = True                    # ★ 들어오자마자 도장
    total = int(maps[x][y])
    for dx, dy in ((-1,0), (1,0), (0,-1), (0,1)):      # 위 아래 왼 오
        nx, ny = x + dx, y + dy
        if 0 <= nx < n and 0 <= ny < m:                 # ★ 경계 검사 (없으면 조용히 틀림)
            if maps[nx][ny] != 'X' and not visited[nx][ny]:
                total += dfs(nx, ny)
    return total

for i in range(n):
    for j in range(m):
        if maps[i][j] != 'X' and not visited[i][j]:
            answer.append(dfs(i, j))        # 덩어리 하나를 통째로 처리
```

### ★★ 그래프 DFS — 덩어리 **개수**만 셀 때  `[0/2]`

```python
visited = [False] * n               # 1차원

def dfs(x):
    visited[x] = True
    for y in range(n):
        if graph[x][y] == 1 and not visited[y]:
            dfs(y)                  # ★ return 없음 — 도장만 찍는다

cnt = 0                             # ★ for문 '밖'
for i in range(n):
    if not visited[i]:              # 도장 없는 애 = 처음 보는 덩어리
        cnt += 1
        dfs(i)
return cnt
```

### ★ 재귀 DFS — 선택형(트리)  `[0/2]`

```python
def dfs(i, total):
    if i == len(arr):                   # ★ 멈추는 줄 (재귀 함수의 첫 줄)
        return 1 if total == target else 0
    plus  = dfs(i+1, total + arr[i])
    minus = dfs(i+1, total - arr[i])
    return plus + minus                 # ★ 합치는 줄
```

**빈칸 2개짜리 틀이다.** 문제가 묻는 것에 따라 두 자리만 바뀐다:

| 묻는 것 | 멈추는 줄 | 합치는 줄 |
|---|---|---|
| 몇 개냐 | `1` / `0` | `plus + minus` |
| 가능하냐 | `True` / `False` | `plus or minus` |
| 최댓값 | 그 값 | `max(plus, minus)` |

### 🔑 `dfs(x)` 인가 `dfs(x, y)` 인가

> **"내가 어디 있는지 말하는 데 숫자 몇 개가 필요한가" = 인자 개수 = `visited`의 차원**

| 입력이 2차원이어도… | 뜻 | 위치 |
|---|---|---|
| `graph[x][y]` = **관계표** ("x와 y가 연결됐나") | 네트워크 | `dfs(x)` · 1차원 visited |
| `maps[x][y]` = **지도** (칸의 내용) | 무인도 여행 | `dfs(x, y)` · 2차원 visited |

**방향 개수와는 무관하다.** 네트워크도 갈 곳이 최대 n군데지만 `dfs(x)` 다.

### ★★★ BFS 큐 — **최단거리는 이것만**  `[0/2]`  (10/21 작성)

```python
from collections import deque

n, m = len(maps), len(maps[0])
dist = [[0]*m for _ in range(n)]      # 0 = 안 가봄
dx, dy = [-1,1,0,0], [0,0,-1,1]

q = deque([(0, 0)])                   # ★ 리스트 안에 튜플
dist[0][0] = 1                        # 칸 수를 셀 때 1 / 이동 횟수면 0 (+ -1 초기화)

while q:                              # ★ 큐가 비면 자동 종료
    x, y = q.popleft()                # ★ popleft — pop 쓰면 DFS가 된다
    for k in range(4):
        nx, ny = x+dx[k], y+dy[k]
        if 0 <= nx < n and 0 <= ny < m:                  # 격자 경계 (출발·도착과 무관!)
            if maps[nx][ny] == 1 and dist[nx][ny] == 0:  # 길 + 안 가봄
                dist[nx][ny] = dist[x][y] + 1            # ★ 나까지 거리 +1
                q.append((nx, ny))                       # ★ 넣을 때 바로 표시

return dist[n-1][m-1] if dist[n-1][m-1] != 0 else -1     # ★ 도착칸 (nx,ny 아님!)
```

**DFS에서 바뀌는 건 두 군데뿐** — `dfs(nx,ny)` → `q.append(...)`, 재귀 → `while q:`.
`visited`·4방향·경계검사는 그대로. **재귀를 안 쓰니 `setrecursionlimit` 불필요.**

### 🔑🔑 시험장 **4단 판단** — 이것부터 한다

```
1. "최소 / 최단 / 몇 번 만에" 가 있나?
       → 예: BFS (deque, popleft). 끝.

2. 제한 N 이 작은가? (N <= 20, 또는 N <= 10 에 순서가 중요)
       → 예: DFS 완전탐색 / 백트래킹 (다 나열해도 된다)

3. 경로 자체나 배치를 만들어내야 하나?
       → 예: DFS. DP로는 안 된다

4. N 이 크고(수백~수십만) "경우의 수 / 최대 / 최소 값" 을 묻나?
       → 예: DP. "마지막 한 수로 쪼개서" 점화식
```

> **1 → 2 → 3 → 4 순서.** 「멀리 뛰기」는 1·2·3을 통과하고 4에 걸린다.
> **거리(횟수)가 답에 들어가면 BFS** / DFS는 **만들어본다** / DP는 **이전 답을 재사용**

### 여러 구간을 거쳐야 하면 — BFS를 **여러 번**

```python
a = bfs(start, lever)
b = bfs(lever, end)
return a + b if a != -1 and b != -1 else -1     # ★ 양쪽 모두 검사
```

🔴 `b` 검사를 빼면 뒷구간이 막혔을 때 `a + 0` 이 나간다 (6만 건 중 2,192건 오답).
**구간마다 `dist`를 새로 만들 것.**

### ★★★ DP 1차원 — **아래에서 위로 쌓기**  `[0/2]`  (10/22 작성)

```python
def solution(n):
    if n == 1: return 1                  # ★ 경계를 맨 앞에서 처리
    dp = [0] * (n+1)
    dp[1], dp[2] = 1, 2                  # ③ 초기값 — 손으로 센 값
    for i in range(3, n+1):              # 🔴 끝값 +1
        dp[i] = (dp[i-1] + dp[i-2]) % 1234567    # ② 점화식 + ★매 단계★ 나머지
    return dp[n]
```

**DP 3단계 — ①이 90%**

| | 단계 | 방법 |
|---|---|---|
| ① | `dp[i]` 의 뜻을 **한국말 문장**으로 | "dp[i] = i칸을 가는 방법의 수" |
| ② | 점화식 | ★ **"마지막 한 수가 몇 가지?"** 그 가지 수만큼 더한다 |
| ③ | 초기값 | 점화식으로 못 구하는 맨 앞을 **손으로 센다** |

- 1칸/2칸 → 2가지 → `dp[i-1]+dp[i-2]` · 1/2/3칸 → `dp[i-1]+dp[i-2]+dp[i-3]`
- 🔴 **나머지는 매 단계.** 끝에만 하면 283배 느림 (20,899자리 수를 10만 번 더한다)
- 🔴 **나머지 숫자가 문제마다 다르다** (`1234567` vs `1000000007`). 제한 조건 확인

### 🔑 DFS인가 DP인가 — **제한 N이 갈라준다**

> **"경우를 하나하나 나열하는 게 물리적으로 가능한가?"**

| 제한 | 경우의 수 | 선택 |
|---|---|---|
| N ≤ 10 (순서 중요) | N! | **DFS** 백트래킹 |
| N ≤ 20 | 2^N ≈ 100만 | **DFS** 완전탐색 |
| N ≥ 수백 | 폭발 | **DP** |

실측: 타겟 넘버(N≤20) 2²⁰=100만 → DFS ✅ / 멀리 뛰기(n≤2000) F(2000)=**418자리** → DP

**경계는 문제의 성질이 아니라 제한이다.** 타겟 넘버는 DP로도 풀린다 (DP가 2,226배 빠름).
**DP가 안 되는 것**: 경로 출력(여행경로) · 상태가 모이지 않음(피로도) · 배치를 만들어야 함

## §5. N 보고 알고리즘 고르기

| N | 허용 복잡도 | 알고리즘 |
|---|---|---|
| ≤ 10 | O(N!) | 순열 완전탐색 (`permutations`) |
| ≤ 20 | O(2^N) | 부분집합, 백트래킹 |
| ≤ 100 | O(N³) | 3중 루프 |
| ≤ 1,000 | O(N²) | 2중 루프, 기본 DP |
| ≤ 100,000 | O(N log N) | **정렬, 이분탐색, 힙** |
| ≤ 1,000,000 | O(N) | 투포인터, 해시, **BFS/DFS** |
| ≥ 10,000,000 | O(log N) | 수학, 이분탐색 |

> **N이 작으면 "다 해봐도 된다"는 힌트다.** 어려운 알고리즘을 찾지 말 것.

| itertools | 언제 |
|---|---|
| `combinations(arr, k)` | 순서 **무관** |
| `permutations(arr, k)` | 순서 **중요** |
| `product(arr, repeat=k)` | 중복 허용 |

- **값이 아니라 자리로 뽑는다** → `'011'` 처럼 중복 값이 있으면 결과도 중복 → `set`으로 받기
- **제너레이터**다. `len()` 안 되고, 한 번만 순회 가능
- 뽑는 개수가 **입력에 따라 변하면** itertools로 안 된다 → 재귀(백트래킹)
