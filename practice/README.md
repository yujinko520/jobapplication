# practice — 직접 풀고 기록하는 곳

## 쓰는 법

1. `_template.py` 를 복사해서 `boj_1234_문제이름.py` 로 만듭니다
2. **먼저 주석으로 설계를 씁니다** (코드 금지!)
3. 구현하고 `python3 practice/boj_1234_문제이름.py` 로 예제를 확인합니다
4. 백준/프로그래머스에 제출합니다
5. 틀렸거나 답을 봤으면 `docs/04-review-log.md` 에 기록합니다

파일명 규칙: `boj_<번호>_<영문이름>.py` / `pg_<문제이름>.py`

## 이미 들어있는 예제 (풀이 과정을 보여주는 용도)

| 파일 | 문제 | 배울 것 |

| `boj_2798_blackjack.py` | [BOJ 2798](https://www.acmicpc.net/problem/2798) | 완전탐색 + 표준입력 처리 |
